# Connectome Star-Map

Fully static 3D citation star-map of real network-neuroscience / brain-connectomics papers.

- 208 OpenAlex papers (Neuroscience concept + connectomics lexicon)
- Edges baked at build time from direct citation and co-citation. Nothing invented.
- Keyword co-occurrence is a documented isolate fallback only.
- react-force-graph-3d + THREE.Sprite glows + UnrealBloomPass + starfield dust

```bash
npm install
npm run dev
```
